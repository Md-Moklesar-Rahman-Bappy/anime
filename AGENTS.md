## 📌 Project Overview

This is a Laravel-based application with:

- ⚙️ Backend: Laravel (PHP)
- 🎨 Frontend: Vite + Tailwind CSS + Alpine.js
- 📊 Libraries: Chart.js, Plyr
- 🔐 CI/CD: GitHub Actions (CI, Testing, Security, Deploy, Release)
