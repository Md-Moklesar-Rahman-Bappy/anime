# Changelog

All notable changes to AniWaves are documented in this file.

## [Unreleased]

- Language support for video servers with language dropdown removal in episode player
- Category support for favorites with video player enhancements
- Video upload functionality with enhanced episode form handling
- Server input handling with x-model data binding
- Episode duration handling with video deletion and scraper integration
- Episode storage refactor and YouTube handling improvements
- Scraper functionality and YouTube integration enhancements
- New controllers, services, migrations, and Episode model updates

## [0.1.0] - 2024

- Initial project setup with Laravel 11
- Basic anime and episode CRUD
- Jikan API integration for MAL imports
- External scraper framework (Gogoanime, Zoro, AnimePahe)
- YouTube video import via oEmbed
- Custom Plyr.io video player
- User authentication via Laravel Breeze
- Admin panel with dashboard, anime, episode, genre, and user management
- Featured slider, genre browsing, A-Z listing, and search/filter
- Watch history, comments, and episode reporting
- Chunked file upload support
- Dark theme UI with Tailwind CSS and Alpine.js
