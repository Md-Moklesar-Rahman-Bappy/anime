# 🔐 Security Policy

Thank you for helping keep the **Anime Project** 🎌 secure.

---

## 📌 Supported Versions

We provide security updates for the following versions:

| Version | Supported |
|--------|-----------|
| 1.x    | ✅ Yes    |
| < 1.0  | ❌ No     |

---

## 🚨 Reporting a Vulnerability

⚠️ **Do NOT report security vulnerabilities in public issues or discussions.**

If you discover a vulnerability, please report it **privately**.

### ✅ Recommended Method

📧 Email: **risingbappy1@gmail.com**  
👉 (Email address)

---

### 📋 Please Include

To help us investigate quickly, provide:

- ✅ Clear description of the vulnerability  
- ✅ Steps to reproduce (if safe)  
- ✅ Affected components (e.g., authentication, API, upload system)  
- ✅ Potential impact (data leak, privilege escalation, etc.)

---

## ⏱️ Our Response Process

We aim to:

- 📩 Acknowledge your report within **48 hours**
- 🔍 Investigate and verify the issue
- 🛠️ Develop and test a fix
- 🚀 Release a secure update
- 🙌 Credit you (optional)

---

## 🔐 Responsible Disclosure

We kindly ask you to:

- ❌ Avoid public disclosure before a fix is released  
- ✅ Provide enough time for resolution  
- ✅ Act in good faith and not exploit the vulnerability  

---

## 🛡️ Security Best Practices

This project follows:

- ✅ Laravel security best practices  
- ✅ Input validation and sanitization  
- ✅ CSRF protection  
- ✅ Authentication via Laravel Breeze  
- ✅ Environment-based configuration (`.env`)  

---

## ⚠️ Sensitive Areas

Contributors and researchers should pay attention to:

- Authentication & authorization  
- File uploads (video handling)  
- External API integrations  
- Scraper functionality  
- Admin panel actions  

---

## 🧪 Testing Security Issues

When testing:

- ✅ Use safe test environments  
- ❌ Do not access other users’ data  
- ❌ Do not perform destructive actions  

---

## 📦 Security Updates

Security fixes will be:

- Released via GitHub Releases  
- Documented in CHANGELOG.md
